##### 1. Write out fully what is meant by:

(a) $\sum\limits_{i=1}^{i=5} i^2$

(b) $\sum\limits_{k=1}^{4} (2k+1)^2$

(c) $\sum\limits_{k=0}^{4} (2k+1)^2$

Solution:

(a) $\sum\limits_{i=1}^{i=5} i^2$

When i = 1, $1^2=1$

When i = 2, $2^2=4$

When i = 3, $3^2=9$

When i = 4, $4^2=16$

When i = 5, $5^2=25$

So

$\sum\limits_{i=1}^{i=5} i^2=1+4+9+16+25=55$

(b) $\sum\limits_{k=1}^{4} (2k+1)^2$

When k = 1, $(2\times 1+1)^2=9$

When k = 2, $(2\times 2+1)^2=25$

When k = 3, $(2\times 3+1)^2=49$

When k = 4, $(2\times 4+1)^2=81$

So

$\sum\limits_{k=1}^{4} (2k+1)^2=9+25+49+81=164$

(c) $\sum\limits_{k=0}^{4} (2k+1)^2$

When k = 0, $(2\times0+1)^2=1$

When k = 1, $(2\times1+1)^2=9$

When k = 2, $(2\times2+1)^2=25$

When k = 3, $(2\times3+1)^2=49$

When k = 4, $(2\times4+1)^2=81$

So

$\sum\limits_{k=0}^{4} (2k+1)^2=1+9+25+49+81=165$

##### 2. Write out fully what is meant by

(a) $\sum\limits_{i=1}^{4} \frac{i}{i+1}$

(b) $\sum\limits_{n=0}^{3} \frac{n+1}{n=2}$

Solution:

(a) $\sum\limits_{i=1}^{4} \frac{i}{i+1}$

When i = 1, $\frac{1}{1+1}=\frac{1}{2}=0.5$

When i = 2, $\frac{2}{2+1}=\frac{2}{3}=0,6666666667$

When i = 3, $\frac{3}{3+1}=\frac{3}{4}=0,75$

When i = 4, $\frac{4}{4+1}=\frac{4}{5}=0.8$

So:

$\sum\limits_{i=1}^{4} \frac{i}{i+1}=0.5+0.667+0.75+0.8=2,717$

(b) $\sum\limits_{n=0}^{3} \frac{n+1}{n+2}$

When n = 0, $\frac{0+1}{0+2}=\frac{1}{2}=0.5$

When n = 1, $\frac{1+1}{1+2}=\frac{2}{3}=0.67$

When n = 2, $\frac{2+1}{2+2}=\frac{3}{4}=0.75$

When n = 3, $\frac{3+1}{3+2}=\frac{4}{5}=0.8$

So:

$\sum\limits_{n=0}^{3} \frac{n+1}{n+2}=0.5+0.67+0.75+0.8=2.72$
