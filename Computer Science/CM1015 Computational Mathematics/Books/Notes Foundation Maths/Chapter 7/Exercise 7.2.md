#### 7.2 Exercises

##### 1. Simplify each of the following

- (4)(3)(7)
- (7)(4)(3)
- (3)(4)(7)

Solution

- (4)(3)(7) = 84
  <br>
- (7)(4)(3) = 84
  <br>

- (3)(4)(7) = 84

---

##### 2. Simplify

- 5 x (4x2)
- (5x4) x 2

Solution

- 5 x (4x2) = 40
- (5x4) x 2 = 40

---

##### 3. Simplify each of the following

- 7(2z)
- 15(2y)
- (2)(3)x
- 9(3a)
- (11)(5a)
- 2(3x)

Solution

- 7(2z) = 14z
  <br>

- 15(2y) = 30y
  <br>

- (2)(3)x = 6x
  <br>

- 9(3a) = 27a
  <br>

- (11)(5a) = 55a
  <br>

- 2(3x) = 6x

---

##### 4. Simplify each of the following

- $5(4x^2)$
- $3(2y^3)$
- $11(2u^2)$
- $(2\times4)\times u^2$
- $(13)(2z^2)$

Solution

- $5(4x^2) = 20x^2$
  <br>

- $3(2y^3) = 6y^3$
  <br>

- $11(2u^2) = 22u^2$
  <br>

- $(2\times4)\times u^2 = 8u^2$
  <br>

- $(13)(2z^2) = 26z^2$

---

##### 5. Simplify

- (7x)(3x)
- 3a(7a)
- 14a(a)

Solution

- (7x)(3x) = $21x^2$
- 3a(7a) = $21a^2$
- 14a(a) = $14a^2$

---

##### 6. Simplify

- 5y(3y)
- 5y+3y

Solution

- 5y(3y) = $15y^2$
- 5y+3y = 8y

---

##### 7. Simplify each of the following

- $(abc)(a^2bc)$
- $(x^2y)(xy)$
- $(xy^2)(xy^2)$

Solution

- $(abc)(a^2bc) = a^3b^2c^2$
  <br>

- $(x^2y)(xy) = x^3y^2$
  <br>

- $(xy^2)(xy^2) = x^2y^4$

---

##### 8. Explain th distinction, if any between

- $(xy^2)(xy^2)$
- $xy^2xy^2$

Solution

- $(xy^2)(xy^2) = x^2y^4$
- $xy^2xy^2 = x^2y^4$

---

##### 9. Explain the distinction, if any between

- $(xy^2)(xy^2)$
- $(xy^2) + (xy^2)$

Solution

- $(xy^2)(xy^2) = x^2y^4$
- $(xy^2) + (xy^2) = 2xy^2$
