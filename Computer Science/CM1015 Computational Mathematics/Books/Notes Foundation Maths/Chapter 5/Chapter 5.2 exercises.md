### Exercise 5.2

1. Evaluate the following without using a calculator:

- $2^4$
- $(\frac{1}{2})^2$
- $1^8$
- $3^5$
- $0^3$

Solution

- $2^4 = 4^2 x 4^2 = 256$
- $(\frac{1}{2})^2 = \frac{1^2}{2^2}= \frac{1}{4} =0.25$
- $1^8 = 1$
- $3^5 = 3x3x3x3x3 = 243$
- $0^3 = 0$

10. Simplify the following

- (a) $(2x)^2 + (3x)^2 - 10x^2$
- (b) $(2x + 3x)^2 - 10x^2$
- (c) $(2x)^2 + (3x- 10x)^2$
- (d) $(2x + 3x- 10x)^2$
- (e) $[(2 + 3)x]^2 - 10x^2$

Solution

- $(2x)^2 + (3x)^2 - 10x^2$
  $(2x)^2 = 2^2*x^2 = 4x^2$
  $(3x)^2 = 3^3*x^2 = 9x^2$
  $4x^2+9x^2-10x^2 = (4+9-10)x^2 = 3x^2$

- $(2x + 3x)^2 - 10x^2$
  $(2x+3x) = 5x$
  $(5x)^2 = 5^2*x^2 = 25x^2$
  $25x^2 - 10x^2 = (25 - 10)x^2 = 15x^2$

- $(2x)^2 + (3x- 10x)^2$
  $(2x^2) = 4x^2$
  $(3x - 10x)^2 = (-7x)^2 = 49x^2 $
  $4x^2 + 49x^2 = (4 + 49x^2) = 53x^2$

- $(2x + 3x - 10x)^2$
  $2x + 3x - 10x = (2+3-10)x = 25x $
  $(-5x)^2 = 25x^2$

- $[(2 + 3)x]^2 - 10x^2$
  $(5x)^2 = 5^2 * x^2 = 25x^2$
  $25x^2 - 10x^2 = (25 - 10)x^2 = 15x^2$
