1. Without using a calculator express each of the following as a proper fraction

- $2^{-2}$
- $2^{-3}$
- $3^{-2}$
- $3^{-3}$
- $5^{-2}$
- $4^{-2}$
- $9^{-1}$
- $11^{-2}$
- $7^{-1}$

Solution

- $2^{-2} = \frac{1}{4}$
- $2^{-3} = \frac{1}{8}$
- $3^{-2} = \frac{1}{9}$
- $3^{-3} = \frac{1}{27}$
- $5^{-2} = \frac{1}{25}$
- $4^{-2} = \frac{1}{16}$
- $9^{-1} = \frac{1}{9}$
- $11^{-2} = \frac{1}{121}$
- $7^{-1} = \frac{1}{7}$

2. Express each of the following as decimal fractions:

- $10^{-1} = \frac{1}{10} = 0.1$
- $10^{-2} = \frac{1}{10^2} = 0.01$
- $10^{-6} = \frac{1}{10^6} = 0.000001$
- $\frac{1}{10^{2}} = 10^{-2}= 0.01$
- $\frac{1}{10^{3}} = 10^{-3}= 0.001$
- $\frac{1}{10^{4}} = 10^{-4}= 0.0001$
