##### 1. Without using a calculator express each of the following as a proper fraction

- $2^{-2}$
- $2^{-3}$
- $3^{-2}$
- $3^{-3}$
- $5^{-2}$
- $4^{-2}$
- $9^{-1}$
- $11^{-2}$
- $7^{-1}$

Solution

- $2^{-2} = \frac{1}{4}$
- $2^{-3} = \frac{1}{8}$
- $3^{-2} = \frac{1}{9}$
- $3^{-3} = \frac{1}{27}$
- $5^{-2} = \frac{1}{25}$
- $4^{-2} = \frac{1}{16}$
- $9^{-1} = \frac{1}{9}$
- $11^{-2} = \frac{1}{121}$
- $7^{-1} = \frac{1}{7}$

##### 3. Write each of the following using only a positive power:

- $x^{-4}$
- $\frac{1}{x^{-5}}$
- $x^{-7}$
- $y^{-2}$
- $\frac{1}{y^{-1}}$
- $y^{-1}$
- $y^{-2}$
- $z^{-1}$
- $\frac{1}{`^{-1}}$

Solution

- $x^{-4} = \frac{1}{x^4}$
- $\frac{1}{x^{-5}} = x^{5}$
- $x^{-7} = \frac{1}{x^7}$
- $y^{-2} = \frac{1}{y^2}$
- $\frac{1}{y^{-1}} = y$
- $y^{-1} = \frac{1}{y}$
- $y^{-2} = \frac{1}{y^2}$
- $z^{-1} = \frac{1}{z}$
- $\frac{1}{z^{-1}} = z$

##### 4. Simplify the following using the laws of indices and write your result only positive powers:

- $x^{-2}x^{-1}$
- $x^{-3}x^{-2}$
- $x^{3}x^{-4}$
- $x^{-4}x^{-9}$
- \(\frac{x^{-2}}{x^{11}}\)
- $(x^{-4})^2$
- $(x^{-3})^3$
- $(x^{3})^{-2}$

Solution

- $x^{-2}x^{-1}$
  $\frac{1}{x^2} \times \frac{1}{x^1}$
  $\frac{1}{x^{2+1}}$
  $\frac{1}{x^{3}}$
  </br>
- $x^{-3}x^{-2}$
  $\frac{1}{x^2} \times \frac{1}{x^2}$
  $\frac{1}{x^{3+2}}$
  $\frac{1}{x^{5}}$
  </br>
- $x^{3}x^{-4}$
  $x^3\times\frac{1}{x^4}$
  $\frac{x^3}{x^4}$
  $\frac{1}{x^1}$
  </br>
- $x^{-4}x^{-9}$
  $\frac{1}{x^4} \times \frac{1}{x^9}$
  $\frac{1}{x^{4+9}}$
  $\frac{1}{x^{13}}$
  </br>
- \(\frac{x^{-2}}{x^{11}}\)
  $\frac{1}{x^2\times x^{11}}$
  $\frac{1}{x^{2+11}}$
  $\frac{1}{x^{13}}$
  </br>

- $(x^{-4})^2$
  $x^{-4 \times 2}$
  $x^{-8}$
  $\frac{1}{8}$
  </br>

- $(x^{-3})^3$
  $x^{-3\times 3}$
  $x^{-9}$
  $\frac{1}{9}$
  </br>
- $(x^{3})^{-2}$
  $x^{3\times-2}$
  $x^{-6}$
  $\frac{1}{x^6}$

##### 5. Simplify

- $a^{13}a^{-2}$
- $x^{-9}x^{-7}$
- $x^{-21}x^{2}x$
- $(4^{-3})^2$

Solution

- $a^{13}a^{-2}$
  $a^{13} \times \frac{1}{a^2}$
  $\frac{a^{13}}{a^2}$
  $a^{13-2}$
  $a^{11}$
  </br>
- $x^{-9}x^{-7}$
  $\frac{1}{x^9} \times \frac{1}{x^7}$
  $\frac{1}{x^{9+7}}$
  $\frac{1}{x^{16}}$
  </br>
- $x^{-21}x^{2}x$
  $\frac{1}{x^{21}}\times x^2\times x$
  $\frac{x^3}{x^{21}}$
  $\frac{1}{x^{21-3}}$
  $\frac{1}{x^{18}}$

  </br>

- $(4^{-3})^2$
  $4^{-6}$
  $\frac{1}{4^{6}}$
