### Exercise 5.2

1. Evaluate the following without using a calculator:

- $2^4$
- $(\frac{1}{2})^2$
- $1^8$
- $3^5$
- $0^3$

Solution

- $2^4 = 4^2 x 4^2 = 256$
- $(\frac{1}{2})^2 = \frac{1^2}{2^2}= \frac{1}{4} =0.25$
- $1^8 = 1$
- $3^5 = 3x3x3x3x3 = 243$
- $0^3 = 0$

---

- $10^5 = 10x10x10x10x10 = 100000$
- $10^6 = = 10x10x10x10x10x10 = 1000000 $

4. Write out fully (a) $a^4b^2c$ and (b) $xy^2z^4$

Solution

- (a) $a^4b^2c = (a*a*a*a)(b*b)c$

- (b) $xy^2z^4 = x(y*y)(z*z*z*z)$

5. Write the folling expressions compactly using indices:

(a) $xxxyyx$
(b) $xxyyzzz$
(c) $xyzxyz$
(d) $abccba$

Solution

(a) $xxxyyx = x^4y^2$
(b) $xxyyzzz = x^2y^2z^3$
(c) $xyzxyz = x^2y^2z^2$
(d) $abccba = a^2b^2c^2$

7. Without using a calculator, find

- $(- 3)^3$
- $(- 2)^2$
- $(- 1)^7$

Solution

- $(- 3)^3 = (-3)(-3)(-3) = -27$
- $(- 2)^2 = (-2)(-2) = 4$
- $(- 1)^7 = (-1)(-1)(-1)(-1)(-1)(-1)(-1) = -1$
