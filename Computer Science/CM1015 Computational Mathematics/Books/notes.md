#### 5.11 Evaluate

a) $(1 + 2^3)^2$

b) $\frac{2^3-1}{2^2+3}$

---

Solution

a) $(1 + 2^3)^2$

- $1 + 2^3 = 1 + 8 = 9$
- $(1 + 2^3)^2 = 9^2 = 81$

b) $\frac{2^3-1}{2^2+3}$

- $\frac{2^3-1}{2^2+3}$
- $2^3-1 = 8^2 - 1 = 7$
- $2^2+3 = 2^2 + 3 = 7$
- $\frac{7}{7} = 1$

#### 5.12 Simplify

$x^2y^2 + 3(xy)^2$

---

Solution

- The bracketed expression is simplified first

$(xy)^2 = (xy)(xy) = x^2y^2$

- So we have

$x^2y^2 + 3(xy)^2 = x^2y^2 + 3x^2y^2$

- $x^2y^2 + 3(xy)^2 = 4x^2y^2$

#### 6.1 The laws of indices

- First law
  $a^m \times a^n = a^{m+n}$

- Second law
  $\frac{a^m}{a^n} = a^{m-n}$

- Key point: any number raised to the power 0 equals 1, that is $a^0 = 1$

- Third law
  $(a^m)^n = a^{mn}$

- Key point: $(a^mb^n)^k = a^{mk}b^{nk}$

#### 6.2 Negative powers
