16. Determine the truth value of each of these statements if the domain of each variable consists of all real numbers.

a) ∃x$(x^2 = 2)$
b) ∃x$(x^2 =−1)$
c) ∀x$(x^2 + 2 ≥ 1)$
d) ∀x$(x^2 ≠ x)$

---

a) ∃x$(x^2 = 2)$

- The symbol ∃ means:
  Meaning of the statement: "There exists at least one real number x such that x squared equals 2"

To prove the statement is true, we need to find a single example that works.
Since the domain is all real numbersm we can solve for x:
$(x^2 = 2)$
$x = \sqrt{2}$ (or $x = -\sqrt{2}$)
The square root of 2 is approximatelt 1.1414...., which is a real number.

Because the the real number is $x = \sqrt{2}$ it satisfies the equation, the existential statement is True.

b) ∃x$(x^2 = −1)$

- The symbol ∃ means:
  Meaning of the statement: "There exists at least one real number x such that x squared equals -1"

To prove the statement works we need to find a single example that works.
$(x^2 = -1)$
$x = \sqrt{-1}$ (or $x = \sqrt{1}$)

$x^2 = -1$
$1^2 = 1$
$1 \neq -1$

The square root of 1 is not a real number, this doesn't satisfies the equation, the statement is False

c) ∀x$(x^2 + 2 ≥ 1)$

Meaning of the statement:

- The symbol ∀ means: "For all integers x"

1. 0 (Destroys multiplication and makes squares equal zero)
   $(x0^2 + 2 ≥ 1)$ = 2 ≥ 1 // True

2. −1 (Flips signs and tests negative cases)
   $(x-1^2 + 2 ≥ 1)$ = 3 ≥ 1 // True

3. 1 (The baseline positive number)
   $(x1^2 + 2 ≥ 1)$ = 3 ≥ 1 // True

4. 0.5 (Fractions get smaller when squared: $0.5^2 = 0.25$ )
   $(x0.5^2 + 2 ≥ 1)$ = 2.25 ≥ 1 // True

Conclusion: Because all test cases are True, the statement is True

d) ∀x$(x^2 ≠ x)$

Meaning of the statement

- The symbol ∀ means: "For all integers x"

1. 0 (Destroys multiplication and makes squares equal zero)
   $(x0^2 ≠ x)$ = 0 ≠ 0 // False

2. −1 (Flips signs and tests negative cases)
   $(x-1^2 ≠ x)$ = 1 ≠ -1 // True

3. 1 (The baseline positive number)
   $(x1^2 ≠ x)$ = 1 ≠ 1 // False

4. 0.5 (Fractions get smaller when squared: $0.5^2 = 0.25$ )
   $(x0.5^2 ≠ x)$ = 0.25 ≠ 0.5 // True

Conclusion: Because counterexamples exist (such as x = 1), the iniversal statement is False
