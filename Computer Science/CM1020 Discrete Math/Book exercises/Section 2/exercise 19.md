19. Suppose that A, B, and C are sets such that A ⊆ B and B ⊆ C.
    Show that A ⊆ C

∈ - element of
⊆ - subset of
⊂ - proper subset of

To prove that A ⊆ C, show that every arbitary element belonging to A must also belong to C.

1. Choose an arbitrary element:
   Let x ∈ A

2. Apply the first premise (A ⊆ B)
   By the definition of a subset, if x ∈ A, then x ∈ B

3. Apply the second premise (B ⊆ C)
   Similarly, because B ⊆ C, any element in B muse also be in C

4. Conclude by definition of subset:
   Because choosing an arbitrarty x ∈ A leads directly to x ∈ C, the conditional statement

∀x(x ∈ A => x ∈ C) holds true. Therefore A ⊆ C
