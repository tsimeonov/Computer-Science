11. Determine wheter each of these statements is true or false

a) 0 ∈ ∅
b) ∅ ∈ {0}
c) {0} ⊂ ∅  
d) ∅ ⊂ {0}
e) {0} ∈ {0}
f) {0} ⊂ {0}
g) {∅} ⊆ {∅}

---

a) 0 ∈ ∅ , this is false

b) ∅ ∈ {0}, this is false

c) {0} ⊂ ∅, this is false

d) ∅ ⊂ {0}, this is true

e) {0} ∈ {0}, this is false

f) {0} ⊂ {0},this is false

g) {∅} ⊆ {∅}, this is true
