9. For each of the following sets, determine whether 2 is an element of that set

a) {x ∈ R | x is an integer greater than 1}
b) {x ∈ R | x is the square of an integer}
c) {2,{2}}
d) {{2}, {{2}}}
e) {{2}, {2, {2}}}
f) {{{2}}}

---

a) {x ∈ R | x is an integer greater than 1}

2 is an element of that set

b) {x ∈ R | x is the square of an integer}

2 is not an element of that set

c) {2,{2}}

2 is an element of that set

d) {{2}, {{2}}}

- {2}: A box containing the number 2
- {{2}}: A box containing another box, which contains the number 2

2 is not an element of that set

e) {{2}, {2, {2}}}

- {2}: A box containg the number 2
- {2, {2}}: A box containing the number 2 and another box with 2

Are either of those two items the bare number 2?
No! They are both sets (boxes)

2 is an not element of that set

f) {{{2}}}

2 is an not element of that set
