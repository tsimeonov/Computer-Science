1. $\in$ (Element of)

- Meaning: "is an element of" or "belongs to".
- How to use it: It connects an item to a set. It means the item is sitting directly inside that exact set (the box).
- Examples:
  - $2 \in \{1, 2, 3\}$ (True: the number 2 is in the set).
  - $\{2\} \in \{1, 2, 3\}$ (False: the box containing a 2 is not in the set).- $\{2\} \in \{\{2\}, 3\}$ (True: the box containing a 2 is in the set).

2. $\subseteq$ (Subset of)

- Meaning: "is a subset of".
- How to use it: It connects a set to another set. It means every item inside the first set is also inside the second set. They are allowed to be exactly identical.
- Examples:
  - $\{1, 2\} \subseteq \{1, 2, 3\}$ (True: 1 and 2 are in the second set).
  - $\{1, 2\} \subseteq \{1, 2\}$ (True: they are allowed to be exactly the same).

3. $\subset$ (Proper Subset of)

- Meaning: "is a proper subset of" (sometimes called a "strict" subset).
- How to use it: It connects a set to another set. It means every item in the first set is in the second set, BUT the second set must be larger. They cannot be exactly identical.
- Examples:
  - $\{1, 2\} \subset \{1, 2, 3\}$ (True: 1 and 2 are there, and the second set has an extra number).
  - $\{1, 2\} \subset \{1, 2\}$ (False: they are exactly the same, so it is not a proper subset).
