25. How many elements does each of these sets have where a and b are distinct elements?

a) P({a, b, {a, b}})
b) P({∅, a, {a}, {{a}}})
c) P(P(∅))

---

a) P({a, b, {a, b}})

1. a
2. b
3. {a,b}

$|P|(S) = 2^3  = 8$

b) P({∅, a, {a}, {{a}}})

1. ∅
2. a
3. {a}
4. {{a}}

$|P|(S) = 2^4  = 16$

c) P(P(∅))

- ∅

  $|P|(S) = 2^1  = 2$
