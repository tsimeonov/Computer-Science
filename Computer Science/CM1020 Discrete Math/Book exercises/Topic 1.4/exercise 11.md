11. Let P(x) be the statement “x = x2.”
    If the domain consists of the integers, what are these truth values?

a) P(0)
b) P(1)
c) P(2)
d) P(−1)
e) ∃xP(x)
f) ∀xP(x)

<details>
     <summary>Solution</summary>

a) P(0) // 0 = 0^2 , True

b) P(1) // 1 = 1^2 , True

c) P(2) // 2 = 2^2, False

d) P(−1) // -1 = -1^2, False

e) ∃xP(x) // true

f) ∀xP(x) // false

</details>
